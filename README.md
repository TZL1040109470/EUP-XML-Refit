## 这是什么 / What is this

EUP XML Refit 是一套面向 GTA V LSPDFR 的配置管理工具，把「一套 LSPDFR 配置」当作项目来管理：

- **19 类配置专属可视化编辑器** —— LSPDFR 原版（7 类）、Ultimate Backup（3 类）、Policing Redefined（9 类）全部有专门编辑器
- **wardrobe.ini 一键转换** —— 老的 EUP 服装配置直接粘贴转换
- **AI 修错** —— 改坏了有自动备份，报错了丢给 AI 分析修复
- **10 种界面语言** —— 跟随系统自动切换
- **纯本地运行** —— 所有数据只在本机处理，不上传任何内容

## 支持范围 / Supported mods

| 配置集 | 覆盖内容 |
| --- | --- |
| **LSPDFR 原版**（7 类） | Outfits 服装、Agency 机构、Loadout 配装、Regions 区域（GTA V 全地区点击选择）、Inventory 武器库（图片选择器）、Backup 增援、Stations 警局、Duty 执勤 |
| **Ultimate Backup**（3 类） | DefaultRegions（14 备份类型全量骨架）、CustomRegions（89 项区域目录网格）、SpecialUnits（响应旗标一键开关）、K9 警犬专属字段 |
| **Policing Redefined**（9 类） | DefaultRegions（18 个内置部门）、Loadouts 武器配装、搜身表 / 车辆搜查表、问话组、呼叫词（34 个内置词网格） |

## 快速开始 / Quick start

1. 下载并安装（或解压便携版）
2. 新建项目，选择你的配置集（LSPDFR / Ultimate Backup / Policing Redefined）
3. 导入现有配置文件，或从零开始编辑
4. 修改完成后导出，替换到游戏目录对应的配置文件中

## 隐私声明 / Privacy

本工具完全离线运行：所有配置读取、编辑、转换、AI 修复均在本机完成，不会向任何服务器上传你的数据。AI 功能仅在你主动触发时工作。
